## 🎯 一句话介绍

> CY 针对用户在了解 AI / Agent 及其衍生项目时面临的**语言障碍**（翻译软件术语不够专业）、**项目过于复杂**（不知道项目要干嘛）、**论述方向过宽**等问题，在用户与项目之间搭建了一座桥梁——用简洁明了的描述提供项目介绍，当用户确认项目对自己有用时，再通过帖子提供的项目地址深入探究。

## ✨ 核心功能

1. **展示 GitHub 上优秀的 AI / Agent 项目介绍**：通过自研 Agent 从 GitHub 拉取优秀项目，经筛选后总结成通俗易懂的帖子发布到 CY，既保证项目权威性，也保证内容通俗易懂。
2. **发布你的问题或 AI / Agent 项目**：问题帖与项目帖有明确区分，发帖时提供简易 Markdown 工具栏，支持图片上传，方便展示帖子内容。
3. **关注开发者，点赞帖子**：为你赞赏的开发者点关注，为你青睐的作品点赞。
4. **评论与私信**：既可以评论他人帖子，也可以与用户私聊。
5. **搜索与分类功能**：作品帖与询问帖明确区分，支持按时间、浏览人数、点赞数排序。
